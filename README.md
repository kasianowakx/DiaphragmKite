DiaphragmKite leverages high-performance real-time processing and integrates machine learning algorithms for optimized data analytics engine functionality.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DiaphragmKite.git`
2. `cd DiaphragmKite`
3. Install in editable mode: `pip install -e .`

## Configuration

DiaphragmKite is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
